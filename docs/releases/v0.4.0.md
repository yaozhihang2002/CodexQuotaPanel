# CodexQuotaPanel v0.4.0 Pre-release

这是面向 Windows 10 / Windows 11 x64 的公开预发布版本。

## 主要更新

- 新增更稳健的智能续航预测：将空闲区间纳入平均，融合 90 分钟短期速度、6 小时长期速度与样本置信度，避免一次突发使用造成过度激进的倒计时。
- 设置页面会在窗口显示后、用户空闲时分批预热，首次切换已预热页面时不再同步创建整页控件。
- 缩小合成绘制范围并优化窗口拉伸、滚轮重绘和远程桌面 DPI 变化时的绘制路径，减少闪烁、残影与中间帧。
- 拆分设置辅助控件、悬浮球、详情面板和转场代码，保持原有设置格式、入口和操作方式不变。
- 完善深色/浅色、中英文、最大字体与远程 DPI 的视觉回归检查。

## 升级与数据

覆盖安装会保留原有设置，包括悬浮球位置、大小、透明度、主题、颜色及交互偏好。程序只在本地读取可用额度事件，不读取 `auth.json`、对话正文或 token，也不会上传额度数据。

## 下载建议

- `CodexQuotaPanel-0.4.0-Setup.exe`：推荐安装包，可选择中文或 English、安装目录及桌面快捷方式。
- `CodexQuotaPanel-0.4.0-portable-x64.zip`：免安装便携包。
- `CodexQuotaPanel-0.4.0-x64.msi`：中文 MSI。
- `CodexQuotaPanel-0.4.0-source.zip`：该版本完整源码。
- `SHA256SUMS-v0.4.0.txt`：下载文件 SHA-256 校验值。

> 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。请仅从本项目 GitHub Releases 页面下载并核对 SHA-256。

---

This is a public pre-release for Windows 10 / Windows 11 x64. It adds a conservative runway forecast, improves settings-page warm-up and rendering, reduces resize/scroll/DPI artifacts, preserves existing settings during upgrades, and expands visual regression coverage. The application processes quota events locally and does not read conversation content or tokens.
