# CodexQuotaPanel v0.4.1 Pre-release

这是面向 Windows 10 / Windows 11 x64 的公开预发布版本。

## 主要更新

- 额度趋势改为按窗口独立保留完整 24 小时的逐分钟原始观测值，不再通过跳过小变化或统一总点数上限压缩精度。
- 鼠标在趋势曲线上移动时会吸附最近的数据点，显示本地时间和当时的剩余额度。
- 修复悬浮球尺寸和设置字体比例被滚轮误改的问题；取消或关闭设置窗口会恢复最后保存的预览状态。
- 精修按钮、选项、滑块和开关的深浅主题、高 DPI 圆角与交互反馈，消除相邻控件从透明边缘露出的白边。
- 进一步拆分大型界面与应用协调代码，并新增一次应用发布、多附件复用的本地发布脚本。

## 升级与数据

覆盖安装会保留原有设置，包括悬浮球位置、大小、透明度、主题、颜色及交互偏好。已有趋势文件保持兼容，程序只在本地读取可用额度事件，不读取 `auth.json`、对话正文或 token，也不会上传额度数据。

## 下载建议

- `CodexQuotaPanel-0.4.1-Setup.exe`：推荐安装包，可选择中文或 English、安装目录及桌面快捷方式。
- `CodexQuotaPanel-0.4.1-portable-x64.zip`：免安装便携包。
- `CodexQuotaPanel-0.4.1-x64.msi`：中文 MSI。
- `CodexQuotaPanel-0.4.1-source.zip`：该版本完整源码。
- `SHA256SUMS-v0.4.1.txt`：下载文件 SHA-256 校验值。

> 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。请仅从本项目 GitHub Releases 页面下载并核对 SHA-256。
