# CodexQuotaPanel v0.5.0 Pre-release

这是面向 Windows 10 / Windows 11 x64 的公开预发布版本。

## 主要更新

- 新增当前重置周期的每日 Token 汇总，悬停可查看精确输入、缓存输入、输出与推理用量，点击可展开每日、模型与周期汇总。
- 本地日志按模型与 `Default` / `Fast` 分类；缺失速率的会话安全回填，显式 `priority` 保持归入 `Fast`。
- 依据 2026-08-24 的 OpenAI 公开 API 价格估算美元成本；Auto-review 等无公开费率的记录明确标记为“未公开计价”。
- 服务端仅返回一个额度窗口时自动改为单环与单额度卡，第二个窗口恢复后自动回到双环与双卡。
- 在显示器、远程桌面和窗口句柄变化后重新确认置顶状态。

## 更小的推荐安装包

- `CodexQuotaPanel-0.5.0-Setup-Web.exe`：推荐。轻量安装器；已安装 .NET 9 Desktop Runtime 时不会下载运行库，缺少时从微软官方下载并验证 SHA-512。
- `CodexQuotaPanel-0.5.0-Setup-Offline.exe`：完整离线安装器，包含运行环境，断网电脑可直接安装。
- `CodexQuotaPanel-0.5.0-portable-lite-x64.zip`：轻量便携版，需要电脑已有 .NET 9 Desktop Runtime。
- `CodexQuotaPanel-0.5.0-portable-offline-x64.zip`：完整离线便携版，不依赖电脑预装 .NET。
- `CodexQuotaPanel-0.5.0-x64.msi`：中文完整离线 MSI。
- `CodexQuotaPanel-0.5.0-source.zip`：该版本完整源码。
- `SHA256SUMS-v0.5.0.txt`：全部下载文件的 SHA-256 校验值。

## 升级与数据

覆盖安装会保留原有设置，包括悬浮球位置、大小、透明度、主题、颜色及交互偏好。轻量版和离线版使用相同升级身份，可以直接覆盖旧版本；安装前处于运行状态时，安装结束后仍按原有规则重新启动。

程序只在本机读取可用额度与结构化 Token 计数事件，不读取 `auth.json` 或对话正文，也不会上传额度、Token、账号或会话内容。美元金额是公开 API 价格的本地等价估算，不是订阅账单或官方额度换算。

> 当前没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。请仅从本项目 GitHub Releases 页面下载并核对 SHA-256。
