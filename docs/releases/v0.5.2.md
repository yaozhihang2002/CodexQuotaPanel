# CodexQuotaPanel v0.5.2 Pre-release

这一版在现有 24 小时额度趋势上增加均匀使用规划参考，帮助判断当前消耗速度是否会让周期后半段额度紧张。原有 Token 统计、悬浮球、详情面板、设置格式与升级后的用户偏好保持兼容。

## 主要变化

- 每个可用额度窗口的趋势图新增均匀使用参考线：当前周期开始为 100%，重置时刻为 0%，中间按时间线性下降。
- 参考线只覆盖当前重置周期；周期外数据或缺少可靠重置时间时不显示，避免误导。
- 真实趋势与参考线均使用更纤细的抗锯齿线条；参考线采用独立暖色与半透明绘制，不遮挡真实曲线。
- 鼠标悬停时同时显示本地时间、实际剩余额度和该时刻的均匀使用参考额度，并高亮两条曲线的对应位置。
- 保留 v0.5.1 的 Token 统计、单/双环自适应、主题、动画、位置、已有设置和覆盖安装兼容性。
