# CodexQuotaPanel v0.6.0 Pre-release

这一版集中提升本地 Token 统计的准确性、刷新速度和可解释性，悬浮球、详情面板、设置格式与升级后的用户偏好保持原有使用方式。

## 主要变化

- 统计引擎同时兼容单次增量和累计 Token 记录，单次增量优先、累计记录兜底，并识别计数器重置。
- 对重复快照、归档副本和分叉日志复制前缀进行事件指纹去重。
- 解析缓存写入 Token，并按有日期标记的公开 API 价格单独估算；金额仍不是订阅账单或额度百分比换算。
- 使用版本化本地缓存跨重启复用未变化文件；追加中的会话只读取新增内容，改写时安全回退到完整重建。
- 使用明细页显示归因覆盖率、缓存命中、增量读取、去重及无法解析记录数量，不把诊断信息塞进悬浮球。
- 保留单/双环自适应、24 小时逐分钟趋势、旧版设置、悬浮球位置和覆盖安装后的启动状态。
