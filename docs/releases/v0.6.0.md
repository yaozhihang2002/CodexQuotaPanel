# v0.6.0 Pre-release

v0.6.0 是 CodexQuotaPanel 的首个 Windows / macOS 跨平台公开测试版本。普通界面与统计核心迁移到 Avalonia，并保留旧版的悬浮球、额度详情、设置、提醒和本地数据能力。

## 主要变化

- 自动识别当前可用额度窗口：只有 7D 或 5H 时显示单环，两者同时存在时恢复双环。
- 详情面板整合额度、均匀使用参考线、续航预测、最早到期重置卡、每日 API 等价美元与模型/速率明细。
- 三种消耗反馈严格沿用 v0.5.2 的视觉语言；低活动状态使用小型冰晶，文字与环、反馈图形保持安全间距。
- Windows/macOS 共用设置、主题、数据解析与预测核心，平台层分别处理置顶、鼠标穿透、启动项和托盘/菜单栏。
- Windows 联网 Setup 约 12.3 MiB，仅在缺少 .NET 10 时从微软官方下载并校验运行库。
- macOS 只提供一个通用 DMG，同时包含 Apple Silicon 与 Intel 二进制。

## 下载

- `CodexQuotaPanel-0.6.0-Windows-Setup.exe`
- `CodexQuotaPanel-0.6.0-macOS.dmg`

Windows 安装器默认简体中文，也可选择 English。覆盖安装会保留位于用户数据目录的设置、悬浮球位置和本地历史。

## 已知边界

- macOS 包经过 GitHub-hosted macOS 构建、签名结构、DMG 完整性与截图矩阵验证，但尚未使用 Apple Developer ID 公证，也尚未完成真人 Retina 设备交互验收。
- Windows/macOS 首次运行都可能显示操作系统针对未公证或未知发布者的安全提示。
- 界面中的美元金额为按标注日期公开 API 费率计算的等价估算，不是订阅账单。
