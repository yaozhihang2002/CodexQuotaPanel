# CodexQuotaPanel v0.6.2 Pre-release

这是一个聚焦 Token 模型归因与升级重建的跨平台小修复版本。

## 修复内容

- 修复 Token 事件早于模型上下文出现时被长期保存为 `Unknown · Default` 的问题。
- 同一日志稍后出现明确模型后，会安全回填前段 Token 记录；实时追加场景也会执行有界重放。
- 升级后自动执行一次有限历史索引，利用稳定事件指纹原位更新最近周期数据，不删除日志，也不会重复累计 Token。
- 不再尝试把 `rate_limits.limit_name` 当作实际模型，因为额度桶名称可能与当前模型不同；没有可靠模型证据的记录仍保持 `Unknown / Unpriced`。
- GitHub 默认分支首页、下载入口和构建说明同步至 v0.6.2。

## 下载

- Windows 10/11 x64：`CodexQuotaPanel-0.6.2-Windows-Setup.exe`
- macOS 12+ Apple Silicon / Intel：`CodexQuotaPanel-0.6.2-macOS.dmg`

Windows 安装器是双语联网安装包，仅在缺少 .NET 10 时从微软下载运行时并验证 SHA-512。macOS DMG 当前使用临时签名，尚未经过 Developer ID 公证和真实 Retina 设备验收。

API 美元金额仍只是按界面标注日期的公开 API 价格进行的等价估算，不是订阅账单或官方额度换算。
