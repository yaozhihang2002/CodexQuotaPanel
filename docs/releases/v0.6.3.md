# CodexQuotaPanel v0.6.3 Pre-release

这是一个聚焦详情面板过渡、悬浮球定位和使用明细排序的跨平台修复版本。

## 修复内容

- 使用明细默认按 API 美元估算从高到低排列，未定价项目置后；金额相同时再按 Token 和名称稳定排序。
- 展开详情前记录悬浮球的实际像素位置，收起时精确恢复，避免多显示器和 DPI 环境下的位置漂移。
- 详情面板每次以当前悬浮球为锚点并约束在所在屏幕工作区；手动移动面板不会改变悬浮球位置或下次展开位置。
- Windows 详情面板使用预绘原生表面、短促淡入和轻微缩放，减少白色首帧、灰闪、标题栏残影和重复圆环。
- Windows 详情面板使用工具窗口样式，仅保留托盘入口，不再在任务栏额外显示图标。
- 悬浮球正常可交互时使用手形光标，只有显式“移动悬浮球”模式使用四向移动光标。

## 下载

- Windows 10/11 x64：`CodexQuotaPanel-0.6.3-Windows-Setup.exe`
- macOS 12+ Apple Silicon / Intel：`CodexQuotaPanel-0.6.3-macOS.dmg`

Windows 安装器是双语联网安装包，仅在缺少 .NET 10 时从微软下载运行时并验证 SHA-512。覆盖安装会保留 LocalAppData 中的设置、悬浮球位置和本地历史数据。

macOS DMG 当前使用临时签名，尚未经过 Developer ID 公证和真实 Retina 设备验收，首次打开可能被 Gatekeeper 提醒。

API 美元金额仍只是按界面标注日期的公开 API 价格进行的等价估算，不是订阅账单或官方额度换算。
