# CodexQuotaPanel v0.6.4 Pre-release

这是一个聚焦 Token 模型归属、精确周期统计和趋势图交互的补丁版本。

## 修复内容

- 重复 Token 事件不再用缺少上下文的 `Unknown` 覆盖已经识别的模型和速率。
- 解析器升级后自动重建近期索引，原位修复当前周期内可恢复的 `Unknown / Unpriced` 记录。
- API 等价美元和每日柱状图按精确重置时刻切分周期，而不是从重置当天零点开始统计。
- 鼠标可在趋势图整个绘图区内移动，按横坐标查看对应时刻的实际额度和均匀使用额度。
- App Server 短时断联时继续显示最近一次可信额度并标记“断联”，不再在实时值与本地快照之间跳动，也不会把保留值重复写入趋势曲线。
- 趋势显示会非破坏性过滤断联期间已经记录的瞬时夹心尖刺，同时保留真正重置后持续存在的新额度。
- 最近一次 App Server 成功额度会安全缓存；应用重启后即使仍断网，也继续显示该可信额度并标记断联，不再回退到本地会话的 100%。
- 缓存额度会在窗口创建前立即呈现，断网启动不再先显示“连接中 / 等待数据”直至实时请求超时。
- 趋势悬停信息固定在曲线上方的独立信息带，横向时间定位保持不变，提示框不再遮挡实际和均匀使用曲线。
- `Auto-review · Fast` 按其 GPT-5.4 基价与官方 2 倍 Fast 倍率计入 API 等价美元，不再显示 Unpriced。

## 下载

- Windows 10/11 x64：`CodexQuotaPanel-0.6.4-Windows-Setup.exe`
- macOS 12+ Apple Silicon / Intel：`CodexQuotaPanel-0.6.4-macOS.dmg`

Windows 安装器是双语联网安装包，仅在缺少 .NET 10 时从微软下载运行时并验证 SHA-512。覆盖安装会保留 LocalAppData 中的设置、悬浮球位置和本地历史数据。

macOS DMG 当前使用临时签名，尚未经过 Developer ID 公证和真实 Retina 设备验收，首次打开可能被 Gatekeeper 提醒。

API 美元金额仍只是按界面标注日期的公开 API 价格进行的等价估算，不是订阅账单或官方额度换算。
