# CodexQuotaPanel v0.6.5 Pre-release

## 2026-09-07 同版本替换更新

- 修复 Windows RDP / 显示配置切换后详情窗口缩放错位、按钮命中位置不一致的自动恢复路径。失效时只重建详情窗口，保留额度数据和悬浮球位置，不增加托盘菜单。
- 按 DWM 实测的可见边框贴屏幕边缘，消除透明缩放边框造成的缝隙；多显示器下重建窗口不会因不可见边框跨屏而误选邻屏。
- 修正首次原生窗口准备判断，窗口句柄已分配不再被误当成绘制就绪。
- 本地 40 项 UI 场景、100%/125%/150%/200% 边框定位几何测试通过；五轮 Windows 原生左右/底部贴边及显示变化重建测得缝隙 0 像素，按钮坐标点击和悬浮球位置保持检查通过。
- 版本号仍为 **0.6.5**。已经安装旧 0.6.5 的 Windows 用户，请重新下载并运行新版 Setup；安装器支持同版本重装并保留用户数据。同版本更新不会被版本号比较自动识别。

## 原有计价与布局更新

- 新增 GPT-6 Astra Default/Fast API 等价美元估算及友好模型名称；已有本地 Token 记录会在汇总时重新计价。
- Astra 每百万 Token 输入 $10、缓存读取 $1、缓存写入 $12.50、输出 $50，Fast ×2；单次输入超过 272K 时输入及缓存 ×2、输出 ×1.5。
- 设置页增加 Astra 价格、缓存写入与长上下文规则，费率核对日期为 2026-09-07。美元为 API 等价估算，不代表订阅账单。
- 核对其他已支持模型的标准单价，无需下调；补齐 GPT-5.5 超过 272K 输入的长上下文加价，并测试阈值边界。历史记录按当前公开价目表重新估算，不作为历史账单。
- 面板贴边定位使用完整窗口尺寸（包括标题栏和边框），并在显示原生窗口后再次校正，避免关闭按钮越界。
- 显示器、工作区或 DPI 变化后合并触发布局重算和重绘；小工作区自动调整窗口尺寸，回到大工作区恢复偏好尺寸。
- 隐藏停放的面板不会被显示变化处理移回桌面；悬浮球位置仍独立。

价格来源：https://developers.openai.com/api/docs/models/gpt-6-astra
GPT-5.5 规则：https://developers.openai.com/api/docs/models/gpt-5.5

验证包括 Astra 计价、同一窗口 100% → 150% → 200% → 100% 连续缩放及工作区变化模拟，以及 Windows 原生标题栏边界截图。模拟测试不等同于真实远程桌面断开/重连验收。
