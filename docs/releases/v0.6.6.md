# CodexQuotaPanel v0.6.6 Pre-release

## 修复内容

- 修复 Windows 点击悬浮球展开时，详情面板在临时位置露出并闪出白色标题栏的问题：首次 Show 前设置原生透明度，准备阶段不激活窗口，完成布局后再正常淡入。
- 移除淡入完成后的重复原生边框刷新，减少标题栏重绘闪烁；保留贴边、显示恢复和悬浮球位置独立行为。
- 每日金额图遵循周期结束时刻不包含在内的规则，避免午夜结束边界额外绘制下一天的空柱。金额仍按精确重置时间区间统计。
- 应用、Windows 双语安装器和 macOS 包版本统一为 0.6.6，首页下载说明同步更新。

## 验证与限制

- 本地完整回归通过：Domain 43、Application 18、Infrastructure 59、Windows Platform 14 项检查，以及 40 项 UI 场景。
- 在 Windows RDP 会话中，旧版采到 7 次“窗口可见但未设置原生透明度”的状态；最终新版连续三轮均为首次可见 alpha=0，未采到同类裸露窗口。
- 五轮原生左右/底部贴边、窗口重建、坐标点击和悬浮球位置检查通过。
- 原生窗口状态采样不是逐帧视频，不代表所有 DPI、显卡或远程重连环境都已验收。
- macOS 使用 ad-hoc 签名，尚未进行 Apple Developer ID 公证与真人 Retina 设备验收。

## 下载

仅提供两个安装入口：

- `CodexQuotaPanel-0.6.6-Windows-Setup.exe`：Windows 10/11 x64，中英文安装界面；缺少 .NET 10 时联网下载微软运行时。
- `CodexQuotaPanel-0.6.6-macOS.dmg`：macOS 12+，同一 DMG 包含 Apple Silicon 与 Intel 程序。

从旧版升级请下载并运行对应安装包，用户设置和本地数据保留。
