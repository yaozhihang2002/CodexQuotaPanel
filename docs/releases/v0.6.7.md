# CodexQuotaPanel v0.6.7 Pre-release

## 更新内容

- 为 GPT-6 Sol 和 GPT-6 Luna 增加 Default/Fast 模型名称与 API 等价美元估算；此前显示为 `Unpriced` 的对应记录可按保存的原始 Token 重新计算，无需清空历史数据。
- 按 2026-09-23 OpenAI 公开 API 费率计算未缓存输入、缓存输入、缓存写入和输出；单次输入超过 272K Token 时应用长上下文费率。此前支持的模型沿用各自原有价格基准。
- 设置页显示两种新模型的公开费率及 GPT-6 系列长上下文规则。金额仅为 API 等价估算，不代表 Codex 订阅账单、额度百分比或实际扣费。

## 验证与限制

- Windows 本地完整回归：Domain 43、Application 18、Infrastructure 59、Windows Platform 14，以及 UI 40 项场景通过；双语联网安装包按同一应用载荷构建。
- macOS DMG 采用 ad-hoc 签名，尚未经过 Apple Developer ID 公证和真人 Retina 设备验收。
- 价格来源：[OpenAI 官方 API 价格](https://developers.openai.com/api/docs/pricing)。其他服务档位、工具调用等额外费用不属于本地 Token 等价估算。

## 下载

仅提供两个安装入口：

- `CodexQuotaPanel-0.6.7-Windows-Setup.exe`：Windows 10/11 x64，中英文安装界面；缺少 .NET 10 时联网下载微软运行时。
- `CodexQuotaPanel-0.6.7-macOS.dmg`：macOS 12+，同一 DMG 包含 Apple Silicon 与 Intel 程序。

覆盖安装会保留现有设置和本地历史数据。
