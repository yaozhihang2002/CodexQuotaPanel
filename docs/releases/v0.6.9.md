# CodexQuotaPanel v0.6.9 Pre-release

## 更新内容

- 修复悬浮球外侧区域被透明、预绘的详情窗口挡住，导致桌面无法点击的问题。详情窗口待命时穿透鼠标，展开后恢复交互。
- 修复 Windows 关机或重启过程中，已关闭的悬浮球被异步动画再次显示而触发的 `.NET` 异常。
- 设置窗口在首次显示前应用 Windows 原生标题栏主题，避免深色主题下标题栏先白后黑。

## 验证与限制

- Windows 本地构建及 Domain 43、Application 18、Infrastructure 59、Platform 14、UI 40 项场景通过。
- 原生窗口测试确认设置 HWND 在 `Show()` 前可应用深色 DWM 标题栏属性，并在 `Show()` 后保持；隔离窗口测试覆盖透明详情窗的鼠标穿透与恢复。
- 尚未在用户电脑上完成安装后的真人视觉检查和实际 Windows 重启验证。macOS DMG 使用 ad-hoc 签名，未经过 Apple Developer ID 公证或真人 Retina 设备验收。

## 下载

本次仍只提供两个安装入口：

- `CodexQuotaPanel-0.6.9-Windows-Setup.exe`：Windows 10/11 x64，中英文安装界面；缺少 .NET 10 时联网下载微软运行时。
- `CodexQuotaPanel-0.6.9-macOS.dmg`：macOS 12+，同一 DMG 包含 Apple Silicon 与 Intel 程序。

覆盖安装保留现有设置和本地历史数据。Windows 安装包未签名，SmartScreen 可能提示“未知发布者”。
