# CodexQuotaPanel v0.7.0 Pre-release

## 更新内容

- 新增 `gpt-6.1-sol` 的使用明细名称和 API 等价美元估算；与 `gpt-6-sol` 分开计价，已有记录会按各自模型重新汇总。
- 按 OpenAI 2026-09-30 官方页面复核已有可选模型的公开 API 标准费率；保留 Default/Fast、缓存写入和单次输入超过 272K 的长上下文规则。
- 设置页只保留估算说明、核对日期和官方价格链接，不再逐个罗列模型费率。

## 价格核对

GPT-6.1 Sol 在 2026-09-29 [API 更新日志](https://developers.openai.com/api/docs/changelog)发布。新旧 Sol 是两个独立型号：新 [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) 的缓存输入价格为 $0.10/百万 Token，旧 [GPT-6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol) 为 $0.20/百万 Token；不能合并计算。其他已有模型费率也已对照官方页面复核，完整价格请以 [OpenAI API 官方价格页](https://developers.openai.com/api/docs/pricing)为准。

金额只是 API 等价估算，不是 Codex 订阅账单、实际扣费或额度换算。Auto-review 是工作负载标签，其后台模型映射本次未重新确认，继续使用此前核对的 GPT-5.4 映射与旧核对日期。

## 验证与限制

- Windows 本地 Release 构建 0 警告；Domain 43、Application 18、Infrastructure 59、Platform 14、UI 40 项场景及原生标题栏测试通过。双语 Setup 与 MSI/MST 构建自检通过。
- macOS 通用 DMG 由 GitHub Actions 生成；其流水线结果与文件应在发布时单独核对，不能以 Windows 本地测试代替。
- 尚未在用户电脑上完成安装后的真人视觉检查和实际 Windows 重启验证。macOS DMG 使用 ad-hoc 签名，未经过 Apple Developer ID 公证或真人 Retina 设备验收。

## 下载

本次仍只提供两个安装入口：

- `CodexQuotaPanel-0.7.0-Windows-Setup.exe`：Windows 10/11 x64，中英文安装界面；缺少 .NET 10 时联网下载微软运行时。
- `CodexQuotaPanel-0.7.0-macOS.dmg`：macOS 12+，同一 DMG 包含 Apple Silicon 与 Intel 程序。

覆盖安装保留现有设置和本地历史数据。Windows 安装包未签名，SmartScreen 可能提示“未知发布者”。
