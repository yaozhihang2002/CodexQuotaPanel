# CodexQuotaPanel v0.8.0 Pre-release

## 更新内容

- 贴边收起：四边闲置 5 秒后，悬浮球原地淡出，清空并等待透明帧完成绘制，再让连续圆角弧线淡入；悬停展开反向进行，两段各约 240 毫秒，不做缩放、移动或变形动画。仅 7 天额度显示单弧，有 5 小时与 7 天额度时显示双弧。左右竖向、上下横向，角落优先左右。减少动态效果时直接切换，移动模式与鼠标穿透时不收起。
- 设置精简：吸附并入贴边收起，移除穿透提醒开关、背景色输入和额度环手动分配；反馈开关与风格、恢复微光与通知分别合并。维护与诊断折叠，保留既有配色配置。版本号固定显示在设置顶部。
- 移除试用版的手动工作计数入口与后台逻辑；保留已有记录文件，不删除用户数据。
- 额度恢复提示：实时确认周期切换且额度回升后轻亮一次；可选安静通知，遵守免打扰与减少动态效果设置。启动、旧快照、倒计时到零不会单独触发。
- GitHub 费率同步：默认每天静默同步，不发送通知；也可在设置中手动同步或关闭自动同步。维护者修改仓库价格表即可更新费率或新增模型，无需重新安装程序。严格校验大小、格式、价格范围和版本；失败保留本地费率。设置不列出各模型价格，仅保留官方链接和简短状态。

## 使用说明

- 贴边收起默认开启；桌面中央的悬浮球保持原样。
- Windows 安装包沿用用户已确认的 0.8.0 r4 本地试用构建；应用版本号保持 0.8.0。
- 价格表由项目维护者核对并发布；本次继续使用 2026-09-30 价格快照，没有虚构新的核对日期。

## 验证边界

Windows 本地构建、UI 回归与单/双弧淡出淡入采样通过，用户已确认试用效果。macOS 包使用 ad-hoc 签名，未经过 Apple Developer ID 公证或真人设备验收。跨显示器/DPI 与实际 Windows 关机重启仍需另行验收。
