# CodexQuotaPanel v0.8.1 Pre-release

- 额度警告默认关闭，可在通知设置中手动开启。
- 每个额度窗口的重置周期最多提醒一次，同时只显示一个警告，不排队补弹。
- 忽略断联、过期和陈旧数据，避免恢复使用后集中弹出提醒。
- 提醒记录保存在本地，重启和保存设置不会重复触发当前周期的提醒。
- 贴边收起等待缩短至 2.5 秒，保留淡出、淡入效果。

## 下载

- Windows：`CodexQuotaPanel-0.8.1-Windows-Setup.exe`
- macOS：`CodexQuotaPanel-0.8.1-macOS.dmg`（Apple Silicon / Intel 通用包）

macOS 安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。
