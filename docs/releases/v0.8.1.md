# CodexQuotaPanel v0.8.1 Pre-release

- 额度警告默认关闭，旧版升级后也默认关闭；可在通知设置中手动开启。
- 开启后每个额度窗口的重置周期最多提醒一次，普通警告升级为严重不足不重复弹窗。
- 同时最多显示一个额度警告，不排队补弹；忽略断联、过期与陈旧快照，避免休眠恢复后堆积提醒。
- 提醒记录保存到本地，关闭弹窗、重启和保存其他设置不会重置当前周期的提醒记录。
- 贴边收起等待由 5 秒改为 2.5 秒，保留先淡出、再淡入的效果。

## 下载

- Windows：`CodexQuotaPanel-0.8.1-Windows-Setup.exe`（用户已确认的本地试用包）。
- macOS：`CodexQuotaPanel-0.8.1-macOS.dmg`（Apple Silicon / Intel 通用包）。

## 验证说明

额度提醒针对性测试、Windows 编译和安装包构建通过。尚未实测朋友电脑整夜休眠恢复的场景；macOS 包为 ad-hoc 签名，未经过 Developer ID 公证或真人设备验收。
