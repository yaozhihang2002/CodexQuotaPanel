# CodexQuotaPanel v0.8.1 Pre-release

- 额度警告默认关闭，旧版升级后也默认关闭；可在通知设置中手动开启。
- 开启后每个额度窗口的重置周期最多提醒一次，普通警告升级为严重不足不重复弹窗。
- 同时最多显示一个额度警告，不排队补弹；忽略断联、过期与陈旧快照，避免休眠恢复后堆积提醒。
- 提醒记录保存到本地，关闭弹窗、重启和保存其他设置不会重置当前周期的提醒记录。
- 贴边收起等待由 5 秒改为 2.5 秒，保留先淡出、再淡入的效果。

## 2026-10-04 同版本修复

- 优化 Windows 远程桌面切换后的悬浮球位置恢复，分别记住本次运行中的本地与远程位置，避免临时屏幕布局覆盖原位置。
- 恢复位置时保留贴边收起状态，不再突然展开后又自动收起；四个屏幕边缘均适用。
- 合并连续显示变化通知；位置和大小无需改变时不再重复隐藏、显示，恢复期间避免误触发鼠标展开。
- 版本号仍为 0.8.1。此前已安装 0.8.1 的用户需重新下载安装包覆盖安装，版本比较不会提示同版本更新。

## 下载

- Windows：`CodexQuotaPanel-0.8.1-Windows-Setup.exe`（用户已确认的本地试用包）。
- macOS：`CodexQuotaPanel-0.8.1-macOS.dmg`（Apple Silicon / Intel 通用包）。

额度提醒与位置恢复针对性测试、Windows 编译和安装包构建通过。用户已确认 Windows rdp4 本地试用效果；这不代表所有 RDP、多屏和 DPI 组合均已实测。尚未实测朋友电脑整夜休眠恢复的场景；macOS 包为 ad-hoc 签名，未经过 Developer ID 公证或真人设备验收。
