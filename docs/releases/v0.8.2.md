# CodexQuotaPanel v0.8.2 Pre-release

- 修复 Windows 远程桌面切换时悬浮球位置跳动的问题，分别记住本次运行中的本地与远程位置。
- 修复恢复位置时贴边弧线突然展开、随后又收起的问题，保持原有的收起或展开状态。
- 合并连续的屏幕变化通知，减少重复隐藏和显示；位置及大小无需变化时保持显示。
- 恢复期间避免误触发鼠标展开，支持屏幕四边的收起状态恢复。

## 下载

- Windows：`CodexQuotaPanel-0.8.2-Windows-Setup.exe`
- macOS：`CodexQuotaPanel-0.8.2-macOS.dmg`（Apple Silicon / Intel 通用包）

Windows 可直接覆盖安装升级。macOS 安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。
