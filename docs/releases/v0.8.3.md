# CodexQuotaPanel v0.8.3 Pre-release

- 修复悬浮球贴边收起后，弧线尾部出现在相邻屏幕的问题。
- 修复收起后与屏幕边缘留有空隙的问题，按实际绘制区域对齐屏幕边缘。
- 修复收起、展开时的位置跳动和闪烁，位置校正在完全透明阶段完成。
- 保留四边吸附和远程桌面切换时的收起状态、位置恢复行为。

## 下载

- Windows：`CodexQuotaPanel-0.8.3-Windows-Setup.exe`
- macOS：`CodexQuotaPanel-0.8.3-macOS.dmg`（Apple Silicon / Intel 通用包）

Windows 可直接覆盖安装升级。macOS 安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。
