# CodexQuotaPanel v0.8.4 Pre-release

- 完善正式版与 Beta 客户端的自动发现，支持通过运行进程、安装注册信息识别自定义安装目录。
- 新增 Credits 余额显示，与重置卡同排展示，无余额时自动隐藏。
- 优化面板布局、浅色配色和趋势图，精简设置说明。
- 面板支持自由调整宽高并记忆尺寸，重新展开及窗口重建后恢复。
- 新增关闭选项：隐藏到托盘或退出应用，可记住选择；点击托盘恢复悬浮球。
- 修复英文安装流程中的 MSI 2356 错误。

## 下载

- Windows：`CodexQuotaPanel-0.8.4-Windows-Setup.exe`
- macOS：`CodexQuotaPanel-0.8.4-macOS.dmg`（Apple Silicon / Intel 通用包）

Windows 可直接覆盖安装升级。macOS 安装包使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。
